# 🩸 BloodConnect – Blood Donation System

## 📌 Project Overview
BloodConnect is a frontend web application developed to connect blood donors with people who need blood. It helps users register as donors, search for donors by blood group and city, and submit blood requests through a simple and user-friendly interface.

## 🎯 Project Objectives
- Make it easier to find blood donors.
- Encourage people to donate blood.
- Allow users to search donors by blood group and city.
- Provide a simple platform for submitting blood requests.
- Organize donor information through a responsive website.

## ✨ Features
- **Home Page:** Introduction to the BloodConnect platform.
- **User Registration:** Registration form with input validation.
- **Login Page:** Basic login form validation.
- **Donor Dashboard:** View donor-related information.
- **Donor Profile:** Display and update profile information.
- **Search Donors:** Filter donors by blood group and city.
- **Blood Request:** Submit blood requests with form validation.
- **Responsive Design:** Navigation bar, cards, and forms designed for different screen sizes.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🧩 Implementation Details
The website uses HTML to structure its pages, CSS to style the interface, and JavaScript to handle form validation, donor filtering, alerts, and page navigation.

This is a frontend prototype. It does not currently use a database or backend server, so registration and blood-request information are not persistently stored.

## 🚀 Future Enhancements
- Integrate a database to store donor information.
- Develop a backend using Python and Django.
- Implement secure user authentication.
- Add location-based donor search.
- Introduce notifications for urgent blood requests.
- Add an administrator dashboard.

## ❤️ Importance
BloodConnect aims to make donor discovery and blood-request submission more accessible through a simple web interface. It demonstrates how web technologies can support awareness and coordination for blood donation.
